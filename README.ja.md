# 2023 アドベンチャーデザイン — RC カーによる C-ITS の実装

[한국어](README.md) · **日本語** · [English](README.en.md)

東国大学校 電子電気工学部 **2023 年度 2 学期 アドベンチャーデザイン** の期末プロジェクト。
Flask 信号サーバー・WiFi 信号機ノード・nRF24L01 無線リンク・自律走行 RC カーを組み合わせ、**C-ITS（Cooperative Intelligent Transport System、次世代高度道路交通システム）** の V2I（車両-インフラ）協調走行を小型ハードウェアで再現した作品です。

## 紹介

実際の C-ITS では、道路インフラ（信号機）が自らの信号フェーズと残り時間を無線でブロードキャストし、車両はそれを受信して停止線の手前で減速・停止・発進を自ら判断します。本プロジェクトはこの流れを 4 つのノードに縮小して実装しました。

```
[Flask 信号サーバー]  --HTTP/JSON-->  [信号機ノード(UNO R4 WiFi)]  --nRF24L01-->  [RF 受信リレー]  --Serial-->  [RC カー]
   信号フェーズ・                       LED・7セグ・サーボ遮断機                    無線信号の中継          停止線 IR + 信号判断
   残り時間の生成                       + 無線ブロードキャスト                                              → 自律停止/発進
```

- **Flask サーバー** が信号フェーズ（赤/黄/緑）とカウントダウンを 3 秒周期で更新し、JSON で提供
- **信号機ノード** が WiFi でサーバーをポーリングして実際の LED・7 セグメント・サーボ遮断機を駆動し、現在の信号を nRF24L01 でブロードキャスト
- **RF 受信リレー** が無線信号を受け取り、Serial で RC カーへ伝達
- **RC カー** が IR 停止線センサーと受信信号を総合し、赤／黄なら停止線で止まり、緑なら通過（Bluetooth による手動操縦も可能）

## ✨ 主な機能 / 動作

| ノード | ファイル | 役割 |
|------|------|------|
| 信号サーバー | `flask.py` | 信号フェーズ・残り時間のステートマシン、JSON API の提供 |
| 信号機ノード | `traffic.ino` | サーバーのポーリング → LED / 7 セグのカウントダウン / サーボ遮断機の駆動 + nRF24L01 ブロードキャスト |
| RF 受信リレー | `rf.ino` | nRF24L01 の信号受信 → Serial への中継 |
| RC カー | `rccar.ino` | Bluetooth 操縦 + IR 停止線検知 + 信号連動の自律停止/発進 |

### 信号ステートマシン（`flask.py`）
- `APScheduler` により **3 秒間隔**（`interval`, `Asia/Seoul`）で信号を更新
- 信号コード: **14 = 赤 (red)**、**15 = 黄 (yellow)**、**16 = 緑 (green)**
- 赤なら `time` を 6→0 にカウントダウン後に緑へ、緑なら 5→0 のカウントダウン後に黄へ、黄なら赤へ遷移
- `GET /` に対して `{ id, description, signal, time }` の JSON を返す（`host=0.0.0.0`, `port=80`）

### 信号機ノード（`traffic.ino`）
- **WiFi (WiFiS3)** で Flask サーバー（`172.20.10.7:80`）に HTTP GET → レスポンス JSON から `signal`・`time` をパース（`ArduinoJson`）
- **信号 LED 3 色**: `r=ピン14`, `y=ピン15`, `g=ピン16`
- **7 セグメント（common-anode）**: セグメントピン `{2,3,4,5,6,7,8,9}`、`digits[10][8]` のパターンで残り時間のカウントダウンを表示
- **サーボ遮断機**（`ピン 10`）: 赤に入ると `write(100)`（下ろす）、緑に入ると `write(10)`（上げる）
- **nRF24L01 送信**: 現在の信号文字（`'r'`/`'y'`/`'g'`）を RC カー側へ無線ブロードキャスト

### RF 受信リレー（`rf.ino`）
- nRF24L01 受信専用 — ラジオで受け取った文字列をそのまま `Serial.write()` で RC カー基板へ伝達

### RC カー制御（`rccar.ino`）
- **Bluetooth（SoftwareSerial）** による手動操縦: `'w'` = 前進、`'x'` = 停止
- **IR 距離センサー**（`A1`）で停止線を検知（アナログ値 `< 400` → 停止線上）
- **信号連動の自律走行**（`motor_drive()`）:
  - 通常の道路（`adc_Ir > 400`）→ Bluetooth コマンドどおりに走行
  - 停止線を検知 + 信号 ≠ 緑（`'g'`）→ **停止**
  - 信号 = 緑 → そのまま通過

## 🛠 技術スタック / ハードウェア

**言語 / フレームワーク**
- Python 3 — Flask, APScheduler（信号サーバー）
- C++（Arduino）— 3 つの `.ino` ノード

**Arduino ライブラリ**
- `WiFiS3`（UNO R4 WiFi）· `ArduinoJson` · `Servo` — 信号機ノード
- `SPI` / `nRF24L01` / `RF24`（nRF24L01 無線リンク）— 信号機ノード・RF 受信リレー
- `SoftwareSerial`（Bluetooth）— RC カー

**ハードウェア（コードから確認できる範囲）**
- MCU: 信号機ノード = Arduino **UNO R4 WiFi**、RC カー / 受信リレー = Arduino（SPI・SoftwareSerial 駆動）
- nRF24L01 2.4GHz 無線モジュール（アドレス `"00001"`, `RF24_PA_MIN`）
- 信号 LED ×3、7 セグメント（common-anode）×1、サーボモーター ×1（遮断機）
- DC モーター ×2 + モータードライバ、IR 距離センサー、Bluetooth モジュール

## 🚀 使い方

### 1. Flask 信号サーバーの起動
```bash
pip install flask apscheduler
python flask.py    # 0.0.0.0:80 で信号 API を提供
```

### 2. 信号機ノード（`traffic.ino`）の書き込み
- Arduino IDE で `WiFiS3` · `ArduinoJson` · `Servo` · `RF24` ライブラリをインストール
- コード冒頭の WiFi SSID / PASSWORD とサーバー IP（`server[]`）を実際の Flask サーバーのアドレスに修正
  （WiFi の資格情報は `arduino_secrets.h` に分離して管理できます）
- UNO R4 WiFi に書き込み

### 3. RF 受信リレー（`rf.ino`）・RC カー（`rccar.ino`）の書き込み
- それぞれ別の Arduino ボードに書き込み
- 受信リレーの Serial 出力を RC カー基板の Serial 入力に接続
- RC カーは Bluetooth ペアリング後に `'w'`/`'x'` で操縦し、信号機ノードのブロードキャストに応じて停止線で自律停止／発進します

## 📁 構成

```
2023_adventure_design/
├─ flask.py       # Python Flask 信号サーバー（信号フェーズ・残り時間のステートマシン + JSON API）
├─ traffic.ino    # 信号機ノード (UNO R4 WiFi): サーバーポーリング → LED/7セグ/サーボ + nRF24L01 ブロードキャスト
├─ rf.ino         # RF 受信リレー（nRF24L01 → Serial 中継）
└─ rccar.ino      # RC カー制御（Bluetooth 操縦 + IR 停止線 + 信号連動の自律走行）
```
